TaskFlow Landing Page ✨

A modern, professional, and fully responsive landing page for a fictional task management application called TaskFlow. Built with Tailwind CSS 🎨, Font Awesome 🔗, and AOS.js 🎬 for smooth animations, it delivers a clean and engaging user experience across all devices.

🚀 Features
Responsive Navbar 📌 – Works on desktop, tablet, and mobile with a toggle menu.
Hero Section 🚀 – Bold headline, product image, and clear call-to-action buttons.
Features Section ⚡ – Showcases task management ✅, reminders ⏰, and collaboration 👥.
Pricing Section 💲 – Three structured plans (Free, Pro, Team) in a modern card layout.
Footer 📩 – Includes quick links, resources, social media icons 🌐, and a newsletter form.
Animations 🎉 – Smooth fade and zoom effects powered by AOS.js.
🛠️ Technologies Used
HTML5 – Structure
Tailwind CSS – Styling & layout
Font Awesome – Icons
AOS.js – Scroll-based animations
📱 Responsiveness

The design is fully responsive and adapts seamlessly to mobile, tablet, and desktop devices.
